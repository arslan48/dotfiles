This repository contains all of my personal dotfiles.

---

## ⚙️ Configuration

This repository includes configuration for:
- **Terminal:** Kitty
- **Shell:** Fish
- **Statusbar:** Waybar
- **Notification:** SwayNC
- **Launcher:** Rofi
- **Audio Visualizer:** Cava
